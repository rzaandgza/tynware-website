FAQ

Questions before you try it.

How does the free trial and purchase work?

Download and install the same signed Windows 11 x64 application without a Tynware account, payment card, purchase or license key. You receive 14 days of full access from first use. After expiry, the application remains accessible for viewing, backup and data export; editing, imports and restore require activation. Your local records are preserved. Buy License opens the TynRent Lemon Squeezy Live checkout directly. Lemon Squeezy delivers your key after purchase. Choose Help → Activate License… in the same installed application. No reinstall or data migration is needed.

Is VAT or sales tax included in the price?

No. The listed €57 is the price before applicable taxes. Depending on your country, Lemon Squeezy may add VAT or sales tax at checkout. The final total, including any applicable taxes, is shown before you pay.

Which Windows versions are officially supported?

The public release targets Windows 11 on x64 (64-bit) Intel/AMD PCs. Windows 10 is not currently in the official support matrix because this release has not been validated there, and macOS is not currently available.

Is TynRent cloud software?

No. TynRent is a Windows desktop application and its core business data is stored locally on your PC.

Does TynRent need an internet connection?

The core inventory and rental workflow is local-first. Internet access is used for license activation and periodic validation.

What happens after the 14-day trial?

Your local data remains available. TynRent switches to read-only mode until a license is activated; backup and export stay available. To purchase, choose Help → Buy License inside the application or use the Buy button on this page. After checkout, return to the same installed application and select Help → Activate License… to paste your key. You do not need to reinstall or migrate data.

Do I need a license key or payment card to try TynRent?

No. Download the same signed Windows installer from this website and use the full-featured 14-day trial without entering payment details or a license key. A purchased license unlocks the same installation.

How many computers can I activate?

A TynRent lifetime license currently allows up to two active devices.

Is this accounting software?

No. Financial reports show booked reservation value. TynRent does not currently track payments, taxes, invoices or accounting ledgers.

Can I back up my data?

Yes. TynRent includes verified backup/restore and user-readable CSV export.
