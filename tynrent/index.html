FAQ

Questions before you try it.

Which Windows versions are officially supported?

The public release targets Windows 11 on x64 (64-bit) Intel/AMD PCs. Windows 10 is not currently in the official support matrix because this release has not been validated there, and macOS is not currently available.

Is TynRent cloud software?

No. TynRent is a Windows desktop application and its core business data is stored locally on your PC.

Does TynRent need an internet connection?

The core inventory and rental workflow is local-first. Internet access is used for license activation and periodic validation.

What happens after the 14-day trial?

Your data remains available. TynRent switches to read-only mode until a license is activated; backup and export remain available.

How many computers can I activate?

A TynRent lifetime license currently allows up to two active devices.

Is this accounting software?

No. Financial reports show booked reservation value. TynRent does not currently track payments, taxes, invoices or accounting ledgers.

Can I back up my data?

Yes. TynRent includes verified backup/restore and user-readable CSV export.
