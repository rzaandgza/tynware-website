The installed application includes a THIRD_PARTY_NOTICES folder containing the applicable license texts, original package notices and an offline LIBRARY_REPLACEMENT.txt guide. The installation's Qt DLLs are dynamically linked; see that guide for the installed paths and replacement instructions.
